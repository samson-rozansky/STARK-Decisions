Illustrative example

Where it stands, honestly.

Built

The full pipeline is implemented on GitHub: criteria commitment, blind scoring, identity-swap test, research loop, hash chain, Ed25519 receipt, in-browser verifier.

The catch

Qwen3.5-27B needs more GPU memory than our 16 GB laptops have. So the live run uses a smaller Qwen3.5 through the same code path, with the same hashing and receipt.

Next: prove the model, not just the scorer.

  1. Zero-knowledge proof of inference — verify the audited weights produced the research output, without revealing the weights. Anthropic's FlashProve (Nov 2026) shows hash-based proofs work today as a prototype, at about 70–95x GPU cost.
  2. Public transparency log — receipts appended to a log, so a platform can't show auditors one model and users another.
  3. Merchant dashboard — every lost decision, the reason, and the receipt to check it.
